# 🌟 TOP Academy Journal Helper - Telegram бот
Данный проект представляет из себя Telegram бота созданного на aiogram, берущий данные из незадокументированного API журнала. 
## ✨ Features
1) Получение данных из журнала
2) Кеширование, часто запрашиваемых данных
3) Сохранение данных от журнала каждого пользователя, шифрование пароля пользователя
4) Просмотр, отправка домашних заданий прямо из бота
